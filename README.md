# Generador de Interfaces Basado en Requisitos - genCodeGherkin

Este proyecto es un generador de interfaces de usuario basado en requisitos escritos en lenguaje natural. Utiliza **Python**, **PyQt5** y **Jinja2** para procesar los requisitos y generar automáticamente interfaces HTML estilizadas.

## Características
- Procesa requisitos escritos en lenguaje natural.
- Genera interfaces HTML dinámicas basadas en plantillas.
- Utiliza **Jinja2** para la generación de plantillas.
- Interfaz gráfica desarrollada con **PyQt5**.
- Estilos personalizados con **Tailwind CSS**.

## Requisitos Previos
Asegúrate de tener instalado:
- Python 3.8 o superior
- pip (gestor de paquetes de Python)

   cd genCodeGherkin

2.Crea un entorno virtual (opcional pero recomendado):
python -m venv .venv
